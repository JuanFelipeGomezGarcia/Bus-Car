# Bus Car - Unity Project

Este es un proyecto de Unity para un juego de Bus Car desarrollado como parte de la maestría en IA.

## Descripción

Proyecto de juego en Unity que incluye:
- Personajes con animaciones
- Efectos de lava
- Controles de tercera persona
- Scripts de movimiento y puntaje

## Estructura del Proyecto

- `Assets/Character/` - Modelos y animaciones de personajes
- `Assets/Scripts/` - Scripts de C# para la lógica del juego
- `Assets/Scenes/` - Escenas de Unity
- `Assets/StarterAssets/` - Assets base de Unity

## Requisitos

- Unity 2022.3 LTS o superior
- Git LFS para archivos grandes

## Instalación

1. Clona el repositorio
2. Abre el proyecto en Unity
3. Ejecuta la escena principal
